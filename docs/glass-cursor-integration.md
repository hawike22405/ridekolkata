# React Bits Pro: Glass Cursor integration

RideKolkata is a Vite / React 19 / Tailwind 4 project. The two authenticated React Bits Pro registries are declared in the root `components.json`; the license key **must not** be committed.

## Complete the licensed installation locally

1. Obtain a valid Starter+ / Pro license from https://pro.reactbits.dev/docs/installation.
2. Create `.env.local` at the project root (this is already ignored by git):

   ```dotenv
   REACTBITS_LICENSE_KEY=your-real-license-key
   ```

3. From the project root, install the official component:

   ```bash
   npx shadcn@latest add @reactbits-starter/glass-cursor-tw
   ```

4. Inspect the CLI output for the installed file path, exported component name, and installed dependencies. The official component's source is supplied by the authenticated registry, **not by this PR**.

## Suggested RideKolkata placement

The current public-facing app is `src/App.tsx` and renders `ConfiguredScene` in `.intro .visual-wrap`. Glass Cursor operates on an image provided through its `src` prop rather than automatically refracting arbitrary DOM elements or the underlying Three.js scene.

For a distinctive Kolkata image effect, add an image panel inside or alongside the intro's `.visual-wrap`, using an existing asset such as `/howrah-bridge.jpg` or `/prinsep-ghat.jpg`. Pass that asset to `GlassCursor`, and keep the 3D `ConfiguredScene` and its refresh button unchanged. **Do not simply overlay it on the 3D scene expecting to refract live WebGL content.**

After confirming the actual installed export/path, the usage should be conceptually like:

```tsx
// Adjust import to the file location generated by the shadcn CLI.
import GlassCursor from "@/src/components/react-bits/glass-cursor";

<div className="relative min-h-[300px] overflow-hidden rounded-2xl">
  <GlassCursor
    width="100%"
    height="100%"
    src="/howrah-bridge.jpg"
    backgroundColor="#000000"
    refraction={0.3}
    borderGlow={0.15}
    blobSize={0.04}
    trailLength={40}
    className="h-full w-full"
  />
</div>
```

Tune the background and accent to the existing tokens in `src/index.css` (dark surface `#000000`, neon green `#00ff66`, light-mode yellow), and check both light and dark themes. The effect is particularly useful in image-led hero content; avoid interfering with links, buttons, focus states, and forms. For touch devices and `prefers-reduced-motion`, provide a static image fallback if the supplied component does not already offer one.

## Verification

Run `npm install`, `npm run lint`, `npm run build`, and `npm test`. Check the hero image on desktop, reduced-motion, touch devices, and in both themes. In particular, confirm the external component does not capture pointer events intended for ride controls.

This PR only prepares the secure registry configuration and the specific integration plan; it **does not install or claim to ship** the private Glass Cursor source code. To complete the feature, run the authenticated CLI command and commit its output plus the tested `src/App.tsx` integration.
