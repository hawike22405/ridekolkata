3D scene configuration

All settings must be supplied explicitly. Saving replaces the complete configuration. Model URLs must point to a .glb or .gltf asset using HTTPS or a root-relative path.

Field guide
  • schemaVersion: 1
  • modelUrl: HTTPS or root-relative asset URL
  • modelScale: 0.001–100
  • modelRotationQuaternion: four numbers [x,y,z,w] with unit length
  • lightingIntensity: 0–20
  • cameraPivotPoints: 1–32 objects, each containing position [x,y,z] and rotationQuaternion [x,y,z,w]
  • cameraFov: 10–120 degrees
  • drivetrainAnimationSpeed: 0–20 radians per second
  • hexColors: background, primary, accent, each in #RRGGBB format

Asset availability and WebGL stability depend on frontend loading and device limits. This editor validates configuration; it does not preview or validate the contents of model files.
